### 上车步骤（照 `Gimbal_test/notes.md`「v1 调试步骤」，这里只写 RS05 版要注意的）

0. 两个 RS05 先各用 RS05_test 查一遍：在私有协议（`scan`），yaw ID 1、pitch ID 2，都接 CAN1。
1. 烧录，上电默认无力（模式 0）。`gimbal_watch.py` 一直读：两个电机的 fb 都是几 ms、fault 00，lk 是 0。车别动，等 valid 变 1（接 24 V，先到温再标定 5 s）。
2. 模式 0 下手转核对方向：yaw 俯视逆时针转，`yaw` 变大；pitch 往上抬，`pitch` 变大。不对就改 `GIMBAL_*_DIRECTION`。同时看 `imu_y`、`imu_p` 是不是一起变大：不一起变，说明 C 板的朝向和 `INS_INSTALL_MATRIX`（现在是单位矩阵）没对上，填好以前别进模式 2，进去环是反的或者开的，电机会一直加速。
3. 中值：扶到正前方、水平，`--once` 读两个 `position_rad`，填 `GIMBAL_*_ZERO_RAD`；烧录后再读，两个 `angle_deg` 应接近 0。中值还是 0 时 `--once` 会提示。
4. pitch 限位：手推到上下极限，读 pitch 的角，往里留几度填 `GIMBAL_PITCH_MIN/MAX_DEG`。yaw 有滑环就保持 ±180。**中值没标定以前别闭环**：限位是按读到的角算的，角在限位外时，一进闭环当前目标就被直接拉到限位上（`Gimbal_AxisControl` 里先把目标限幅，不走斜坡），云台会全速往那边走，可能撞机械限位。
5. 第一次闭环：电流限幅先保持 1 A，模式 1，`add yaw 5`、`add pitch 5`。PID 先按惯量换算初值（「调 PID」的「初值怎么给」：速度环 Kp、Ki 按惯量的倍数放大，角度环 Kp 先不动）。不换算的话，惯量大几倍，速度环带宽就低几倍，角度环 Kp 12 离它太近，阶跃超调变大、来回晃。惯量可以从 CAD 里读，或者照「调 PID」里的估法（已知电流看角加速度）。
6. 调 PID（v1 第 4、5 步）。pitch 有重力，P 不够会下垂，加 I 或 `GIMBAL_PITCH_GRAVITY_FF`。
7. 保护：闭环时拔掉 pitch 的 CAN 线（或给 pitch 断电），整个云台应该无力、lk 变 1；插回去仍然锁着，给一次模式 0 才解开。yaw 也试一次。
8. 模式 2（IMU）：第 2 步确认过同向、安装矩阵填好以后再切。

### 方向的标准（2026-11-11 整理，按第一版机械：yaw 齿轮、pitch 四连杆、C 板在炮管上）

全车约定：yaw 俯视逆时针为正，pitch 抬头为正。每一项都对着这个约定单独核对，不是拿两个量互相对：编码器不对改方向宏，IMU 不对改安装矩阵。都在模式 0 下用手转，`gimbal_watch.py` 一直读。

| 量 | 看哪一列 | 正确的样子 | 不对就改 |
|---|---|---|---|
| yaw 编码器角 | `yaw` | 云台俯视逆时针转，变大 | `GIMBAL_YAW_DIRECTION`。只看云台俯视逆时针转时，从输出轴那面看电机怎么转：逆时针（电机反转）是 −1，顺时针是 1，和中间几级齿轮、电机怎么装无关。11-11 用户确认从输出轴那面看电机逆时针时云台俯视逆时针：−1，就是现在的值。上车再手转确认 |
| pitch 编码器角 | `pitch` | 在选定的那一段里，抬炮口变大。过了连杆最高点方向反过来，那边不用 | `GIMBAL_PITCH_DIRECTION`（按这一段定；用户 11-11 说从输出轴看顺时针是抬头，现在是 1） |
| IMU yaw | `imu_y` | 云台俯视逆时针转，变大。`yaw` 列跟着同向变，但变的是电机角，约为 `imu_y` 的传动比倍 | `INS_INSTALL_MATRIX` |
| IMU pitch | `imu_p` | 抬炮口变大。C 板在炮管上，`imu_p` 就是炮管的真实角度；和 `pitch` 列同向，但不是 1:1 | `INS_INSTALL_MATRIX` |
| 电流 | `y_I`、`p_I`（已经乘过方向） | 闭环时手往正方向推，电流变负（往回顶） | 方向宏对了它就对；方向错了一闭环就会自己跑掉 |
| 指令 | `add yaw 5`、`add pitch 5` | 往正方向走。yaw 是电机走 5°（云台走 5° ÷ 传动比），pitch 是曲柄走 5° | 同上 |

### 上车的成功标准（2026-11-11 整理；标“建议”的数是 Claude 定的，不是实测）

0. 先弄清两件事：
   - yaw 的传动比 N：问机械要齿数最准。或者模式 0 下手转云台 30° 左右，看 `imu_y` 变了多少、`--once` 里 yaw 的 `position_rad` 变了多少：N ≈ |Δposition_rad| × 57.3 ÷ |Δimu_y|（转的时候 `position_rad` 别跨过 ±12.57，那里会跳 8π）。
   - pitch 的“炮管角–电机角”曲线：模式 0 从最下慢慢推到最上，一直读，记 `pitch` 和 `imu_p`。找出 `imu_p` 到最大、再往上推反而变小的那一点（最高点），要用的 pitch 范围要放得进最高点一侧的单调段。
1. 上电：默认模式 0，云台不动。两个电机 fb 几 ms、fault 00、state 0；CAN1 TEC 0、没有错误。接 24 V、车不动时，温度到 40 ℃ 并稳在 ±0.25 ℃ 以内，cal 数到 5000，valid 变 1（记下用了多久）；恒温以后加热占空比低于 70%。
2. 总线和滑环：断电量 CANH–CANL 约 60 Ω（根目录 notes 第 4 节）。模式 0 下手推云台慢慢转几整圈，TEC 一直是 0、不进 BUS-OFF，两个电机的 fb 一直是几 ms（滑环接触不好时会断）。
3. 方向：上表每一行都对。
4. 中值、限位：
   - pitch：中值标在炮管水平处（`imu_p` ≈ 0）；`GIMBAL_PITCH_MIN/MAX_DEG`（电机角）限在单调的那一段里，离最高点留足余量（建议至少 10° 电机角）。闭环里给超过限位的目标，停在软限位，碰不到机械限位，也到不了最高点。
   - pitch 电机直接带曲柄，中值能写死：整车断电重启，同一个位置读数不变（建议差 0.5° 以内）。这一条就是 RS05_test 第 5 步还没做的上电绝对角。
   - yaw：N = 1 时和 pitch 一样（扶到正前方标中值，断电重启读数不变）。N ≠ 1 时中值写不死（上电时 yaw 有好几种可能），这一版不标 yaw 中值、不验这一条，`gimbal_yaw.angle_deg` 只当相对角用。
5. 编码器闭环（模式 1）。编码器模式的角是电机角，云台真实的角看 `imu_y`、`imu_p`：
   - 进模式 1 不跳；`add yaw 5`、`add pitch 5` 方向对、停得住。
   - 编码器稳态误差小于 0.1°（建议；台子上空载 yaw < 0.02°，RS05 分辨率约 0.022°）。pitch 在那一段的两头都不下垂。
   - 手推一下松开能回位，最多冲过头一次，不来回摆；静止时不嗡嗡响，电流抖动小于 0.1 A（建议；台子上 ±0.04 A）。
   - 10° 方波（`yaw_square_deg` / `pitch_square_deg`）不来回摆，冲过头不超过 1.5°（建议）。台子上 1 A 限幅时斜坡停下就冲过头 1.1~1.5°，是刹车能力决定的；惯量大了会更多，放开电流限幅能减小。
   - 斜坡（100°/s）走的过程中 `target − angle` 小于 1°（建议）。
   - 齿隙：电机停住时轻轻来回推云台，记 `imu_y` 能晃多少度。编码器模式里看不出来（电机不动），到 IMU 模式它就在环里了。
6. 保护：闭环时拔掉 yaw 或 pitch 任意一个的 CAN 线（或给它断电），100 ms 内两个电机都无力、lk 变 1；插回去还是锁着，给一次模式 0 才能重新闭环。拔之前扶住炮管：pitch 一无力就往下掉。
7. IMU 模式（模式 2；上表 IMU 两行对了，pitch 限位保证到不了最高点）：
   - 0 / 1 / 2 来回切不跳（建议 0.5° 以内），1 ↔ 2 切换时 pitch 不往下掉。
   - 停住时不来回找。在齿隙里来回找的话记下幅度，这是机械的问题（第二版改 1:1 或同步带）。
   - 手慢慢把底盘转 ±90°：转的时候 `imu_y` 偏离小于 1°，停下后回到 0.2° 以内（建议）。
   - 把底盘前面或后面抬起几厘米：`imu_p` 不变（建议 1° 以内）。
   - 静止 5 分钟，记 yaw 漂了多少（没有磁力计会漂；10-30 没恒温时台子上约 0.3°/分钟）。
   - IMU 失效锁定这一条先不做：用暂停调试器的办法，暂停超过 100 ms RS05 也会掉线，分不清是谁锁的；不停核写 `BMI088_DATA.initialized` 脚本现在不支持。
   - 加了齿轮、连杆以后等效增益都变了（pitch 还随位置变，按最陡的那头调），模式 1、2 的 PID 都按车上重调，台子上那组只当起点。
8. 全程 CAN1 TEC 0、不进 BUS-OFF，电机不烫手。都过了以后，把传动比、pitch 曲线、中值、限位、PID 记进 notes，再定要不要放开 1 A 的电流限幅。

还没有的：遥控器（DR16 + robot_cmd，接口见 `Gimbal_test/notes.md`），这一版靠调试器 / 脚本发指令，底盘落地跑之前要有它。摩擦前馈第一版保持 0；`yaw_friction.py` 的提示还是按台子写的，第一版不用它。

## CAN（细节见 `Gimbal_test/notes.md`「换 RS05」的「CAN」）

- **`.ioc` 里 `NART` 的意思**：CubeMX 数据库里 `NART` 这一项就叫 "Automatic Retransmission"，`ENABLE` 才是打开重发，默认 `DISABLE`。2026-11-08 先写成 `DISABLE`，生成出来是 `AutoRetransmission = DISABLE`，改成 `ENABLE` 才对。以前 notes 里"`NART=DISABLE` 生成 `ENABLE`"的说法是错的。
- CAN1 上每周期三帧：两个 RS05 各一帧（RELAX 时是停止帧，反馈全靠应答）+ 0x110，正好占满 3 个发送邮箱，这一路别再加周期帧。负载约 64%~78%。
- 过滤器：CAN1 组 1，只收 RS05 的类型 2。这一版云台板不收别的帧（底盘 → 云台的回传帧还没有）；以后要收，得在 CAN1 再配一个组。
- CAN2 不启动：以后发射机构接 CAN2 时，robot.c 里加它的 manager 并 Start。

### 要注意的

1. **C 板拿在手里时别用模式 2。** IMU 模式的反馈是 C 板的角度和角速度，电机转了 C 板测不到，误差消不掉，电机会一直加速（主机模型里给 10° 误差，1 s 后 1622°/s）。
2. **C 板装到云台上以后别用模式 3。** 那时电机一转 IMU 也跟着转，目标就跟着电机跑；底盘转一下或者 yaw 漂一点，云台就一直转下去（主机模型里底盘转 10° 以后，云台以约 100°/s 一直转）。
3. 斜坡限 100°/s：C 板转得更快时电机落在后面，C 板停下后再追上；停下时冲过头 1~2°（前馈突然归零，和「v1 调试步骤」第 5 条说的一样）。落后超过 180° 时电机会掉头走近路，最后朝向一样（yaw 不限位，按最短方向走）。
4. 匀速转时电机落后一点：速度环只有 P，克服摩擦要一点误差。主机模型里 90°/s 时落后 0.4°，和速度成正比（和主机测试 `imu_spin` 场景 360°/s 落后约 1.5° 是一回事）。真电机的摩擦不一样，以实测为准。
5. 中值 `GIMBAL_YAW_ZERO_RAD` 还是占位的 0。模式 3 跟的是变化量，不受影响。
6. PID 是占位值，是按带负载的云台估的（主机模型 J = 0.005 kg·m²）。推断（没测过）：光一个电机、转盘上什么都没装时转动惯量小得多，同样的速度环 Kp，环路增益大很多，可能会抖、嗡嗡响。抖的话先把 `GIMBAL_YAW_SPEED_KP` 往小调（比如减半再减半）。电流限幅还是 1 A。
7. CLion 暂停超过 100 ms，RS05 自己进 Reset（canTimeout），继续运行后驱动约 5 ms 重新使能。暂停时别转 C 板：暂停期间没有采样，陀螺仪积不到这段转动，C 板 yaw 就少了这一段，电机不会补。
8. 没有磁力计，C 板 yaw 会慢慢漂（2026-10-30 没恒温时静止约 0.3°/分钟）。所以模式 3 下 C 板不动，电机也会跟着慢慢转。

#### 初值怎么给、怎么调（这次用的办法，装上云台以后照这个重调）

- 单位：速度环 Kp 是 A/(°/s)，Ki 是 A/(°/s·s)；角度环 Kp 是 (°/s)/°，也就是 1/s，它本身就是角度环的带宽（rad/s）。
- 初值按带宽给，J 是转动惯量（kg·m²），Kt 是力矩常数（RS05 约 0.67 N·m/A）：
  - 速度环 Kp = ω_v × J / Kt × π/180。ω_v 是速度环带宽，先取 50~100 rad/s。
  - 速度环 Ki = Kp × ω_v / (5~10)。
  - 角度环 Kp = ω_v / (4~5)。
  - 其余（角度环 Ki、Kd，速度环 Kd）都先给 0。
- J 的估法：给一个已知电流，看角加速度，J = Kt × I / α。这次是从斜坡停下时的减速估的：1 A 时约 100 rad/s²，J ≈ 0.0067 kg·m²。只测了一次，摩擦也算在里面，是粗估。
- 按这个公式反推，这次定的那组对得上：Kp 0.016 对应 ω_v ≈ 92 rad/s；Ki / Kp = 12.5，约为 ω_v / 7；角度环 Kp 12 约为 ω_v / 7.7。
- 装上负载以后：J 变大几倍，速度环 Kp、Ki 就先按同样的倍数放大当初值，角度环 Kp 先不动。
- 顺序：先内后外。
  1. 速度环 Kp 往上加，直到静止时电流噪声（Kp × 转速噪声）或者嗡嗡声受不了、或者开始振荡，再退一些。这次加到 0.024 也没振荡，噪声 ±0.07 A，取了 0.016。
  2. 加速度环 Ki，消掉静摩擦、重力留下的稳态误差；看停住以后会不会来回找（积分加静摩擦会这样）。
  3. 角度环 Kp 往上加，看阶跃的超调和调节时间，再看跟正弦 / 跟随时的误差。
  4. 每一步都用同样的阶跃（±5°、±10°、±20°）和同样的正弦比较。
- 不要两个环都加 I；角度环一般也不用 D，速度环本身就起阻尼的作用。
- 改 Ki 之前先清积分（见上面「Ki = 0 时积分照样在攒」）。

#### yaw 超调怎么解决（2026-11-12 用户问；分析，没改代码）

- 超调的来源（上面的数据）：斜坡以 100°/s 走到目标就突然停，速度前馈一下没了；1 A 时电机只能以约 1700~2000°/s² 减速，从 110~130°/s 刹停要 3~4°；刹车的 −1 A 还让炮头在软齿轮上往前甩约 2°。PID 只能靠调慢（角度环 Kp 低）来压，代价是被摩擦粘住，所以 PID 解决不了。
- 办法（按效果排；1、3 是控制代码，用户先写）：
  1. **斜坡加加速度限制（梯形速度曲线）**：每个轴多存一个“斜坡速度”。每周期按剩下的距离算“现在开始以最大减速度刹车、正好停在目标”的速度 √(2·a·|剩下|)，期望速度取它和最大速度里小的那个；斜坡速度往期望速度靠，每周期最多变 a·dt；目标按斜坡速度走，速度前馈就用斜坡速度。a 取实测能力的一半左右（约 800~1000°/s²），需要的电流 ≈ J·a/Kt ≈ 0.02 × 17 / 0.67 ≈ 0.5 A + 摩擦，不顶 1 A 限幅，速度环跟得住，到终点时速度是 0，炮头也不被猛拽。10° 时加速 0.1 s、减速 0.1 s，总共约 0.2 s。小阶跃也不会再被 100°/s 的前馈踢一下。还可以再加加速度前馈（电流 = J·α / Kt），让速度环不用靠误差去产生加速的电流。
  2. 只改参数的临时办法：`GIMBAL_RAMP_DEG_PER_MS` 从 0.1 降到 0.05（50°/s），刹车距离按速度平方降到约 1/4，但大角度转得慢一倍。放大电流限幅帮助不大：刹得快了，但炮头甩出去的量和刹车力矩成正比，会更大。
  3. 模式 2 的速度环改用电机转速（见上面的结论）。
- 顺便发现（2026-11-12，读板子看到的）：**模式 2 下目标被软限位截住时，速度前馈会混进噪声**。`Gimbal_AxisControl` 每周期用当前的“IMU − 编码器”差（offset）把目标换到编码器系里限位，被截住时 diff = goal − cur 里的 offset 抵不掉；编码器一格 0.022°，offset 一跳，diff 就是 0.022°，前馈 = 0.022 / 1 ms = 22°/s，电流被踢 0.013 × 22 ≈ 0.29 A。pitch 顶在下限时 p_I 在 +0.24 / −0.05 A 之间跳就是这个（当时速度目标 −17°/s、角度环只给 +3.96）。模式 1 下 offset 恒为 0，不受影响。改法（控制代码，用户先写）：目标被限位截住的那个周期前馈给 0，或者前馈只按指令本身的变化算。

用户的想法：底盘转的时候云台先被带走一点再回来，想加底盘角速度前馈：底盘板把自己陀螺仪的角速度经板间帧发给云台。下面是 Claude 的建议。

- **IMU 模式下，底盘角速度不能加到速度环目标上。** 这时速度环的反馈已经是对地角速度 `gimbal_imu.yaw_rate_dps`，云台对地不动时目标本来就是 0。“速度目标减底盘角速度”只在速度环反馈用电机转速（相对底盘）时才对，在那里它是把相对转速换成对地转速。这里再减一次：底盘 180°/s 时稳态对地差 15°（= 180 / 角度环 Kp 12）；底盘超过 200°/s（角度环输出限幅）时云台对地一直转。
- 底盘带着云台转，靠的是 yaw 电机减速箱、轴承（上车后还有滑环、线）的摩擦。摩擦看的是电机相对底盘的转速，也就是 `gimbal_yaw.rate_dps`（RS05 自己报的，每个模式都在算）。建议前馈加在电流上、用这个转速：`i_ff = i_c × clamp(rate_dps / 带宽, −1, 1) + b × rate_dps`。和 pitch 重力前馈一样，在 `Gimbal_Update` 里两个闭环模式都加，系数给 0 就是关。
  - 云台对地不动时 rate_dps = −底盘角速度，和底盘陀螺仪测的是同一个量。云台自己转（瞄准、斜坡）时的摩擦也包括在内。不用板间帧，单板、底盘板掉线时都能用。
  - 走底盘陀螺仪要做的：F405 的 .ioc 还没配 SPI1，BMI088 在这块板上没驱动过；云台板 CAN1 现在只收 RS05 类型 2，要再配一个过滤器组；CAN1（两个 RS05 + 0x110）约 64%~78%，再加 1 kHz 一帧约 75%~92%。
  - 别处要用底盘角速度时，云台板自己能算：ins 的 `yaw_rate_dps` − `gimbal_yaw.rate_dps`（平地上）。
- 要注意的：
  - rate_dps 里有云台自己的转速，所以这个前馈在环里。补得比真实摩擦小，效果就是摩擦变小；补过头等于往运动方向推，低速时会来回找，严重时可能自激。系数按实测偏小取，剩下的交给速度环积分。桌上静摩擦 0.03~0.15 A、随位置和方向变，按小的那头取。
  - 库仑项不能直接用 sgn：静止时 RS05 转速噪声约 ±2.5°/s，电流会在 ±i_c 之间来回跳，所以在 ±带宽 内线性过渡。带宽越窄，起转时前馈到得越早：下面的粘滑模型里（底盘 0.5 s 转到 360°/s、前馈 80%），带宽 5 / 10 / 25°/s 时对地偏差峰值是 0.039 / 0.049 / 0.078°。但带宽越窄，静止时电流跟着噪声抖得越厉害，带宽内前馈随转速的斜率 i_c / 带宽 也越大（要比速度环 Kp 0.016 A/(°/s) 小）。先试 10°/s 左右，看静止时电流抖不抖。同日早些时候写的“20~30°/s”偏宽，已按模型结果改掉；后来主机模型里又扫了一遍，见「验证」，10°/s 不变。
  - **粘住的那一下补不了**（用户问：刚开始云台被带着走，相对转速不是 0 吗）。要分两段看：
    - 粘住：云台和底盘一起转，相对转速 = 0。这时是静摩擦，大小“要多少给多少”，最多到最大静摩擦，不是相对转速的函数，什么前馈都算不出来，只能靠反馈：IMU 一测到云台在转，速度环就往回推，推力超过最大静摩擦就脱开。桌上最大静摩擦 0.03~0.15 A、速度环 Kp 0.016，云台对地最多被拖到约 2~9°/s 就脱开；底盘角加速度 × 云台转动惯量超过最大静摩擦时，光惯性就把它拽开了，根本不粘。
    - 脱开以后：被带走的大头在这一段。云台对地只有几 °/s，底盘已经几十、几百 °/s，相对转速 ≈ −底盘角速度，离 0 很远。这时是动摩擦，大小由相对转速定，前馈补的就是这部分。
    - 粘滑模型（`%TEMP%\ff_stick.py`，没进仓库。摩擦是猜的：最大静摩擦 0.12 A、动摩擦 0.08 A，粘滞和主机测试一样；PID、J 用桌上的）：云台对地最快只到 3.7~4.3°/s。底盘 0.5 s 转到 360°/s：不粘，50 ms 时底盘 36°/s、云台 2°/s；对地偏差峰值 0.177°，加前馈（80%、带宽 10°/s）后 0.049°。底盘 2 s 转到 360°/s：先粘 24 ms，0.170° → 0.118°，粘住那段前馈帮不上。
  - 前馈的参数先测一次、写成宏（和 `GIMBAL_PITCH_GRAVITY_FF` 一样），运行时每毫秒把实时的相对转速代进去算。测不准、随位置和温度变的那部分交给速度环积分。机械变了（装上云台负载、滑环、换线）要重测。
  - 匀速转时，速度环积分已经把摩擦抵掉了（主机测试小陀螺稳态落后 0.00°）。前馈管的是起转、停下、换向、变速时那一下。

  | 80%，带宽 3 / 5 / 20 | 0.040 / 0.045 / 0.075 | 0.089 / 0.095 / 0.127 | 0.012 / 0.012 / 0.013 | 0.004 / 0.017 / 0.095 | −0.067 / −0.072 / −0.007 |

  - 符号对时起转快的那种小到约 1/3，符号反时变大约 1.8 倍：上板时符号错了是看得出来的。
  - 起转慢时帮得少：先粘住一段（前馈帮不上），之后相对转速在带宽里待得久。
  - **底盘慢慢停下时前馈反而让偏差变大**（0.015 → 0.058）：快停时相对转速进了带宽，前馈线性收掉，实际的库仑摩擦一直是满的，直到粘住。没前馈时速度环积分正好顶着这份库仑摩擦。
  - 带宽窄了起转、停下都好，但编码器模式停到目标时误差变大（−0.007 → −0.07）：带宽里前馈随转速的斜率 i_c / 带宽（带宽 5 时 0.0128 A/(°/s)）快赶上速度环 Kp 0.016，低速时阻尼几乎没了。带宽 10°/s（斜率 0.0064）两头都还行，先用它。真转速噪声 ±2.5°/s，带宽越窄静止时电流抖得越厉害（模型里没加这个噪声）。
  - 补过头（150%）各项都比 80%、100% 差，停到目标时差 0.066°：往运动方向推。
  - 模型参数是猜的（摩擦、惯量 0.005 kg·m²），数只说明方向和量级。

### 上板怎么测

1. 转盘上别接线、别有东西挡着（每趟转一圈多；带负载没关系），电机机身固定住，C 板从转盘上拿开。接 24 V，烧现在的程序（前馈系数是 0）。先连着跑几次，后面几次的摩擦不再比前面小了，删掉 csv 再正式测。
2. 跑 `yaw_friction.py`（100°/s）。再把 `GIMBAL_RAMP_DEG_PER_MS` 改成 0.03 烧、跑一次；改成 0.3、`GIMBAL_SPEED_LIMIT_DPS` 改成 400 烧、跑一次。测完两个宏改回 0.1、200。
3. `yaw_friction.py fit`，把打出来的两个宏填进 `gimbal_config.h`，烧。
4. 验符号：再跑一次 `yaw_friction.py`。总电流应该和第 2 步差不多，“其中速度环”那份降到总电流的两三成，不报“反号”。
5. 静止时看一眼电流抖不抖（gimbal_watch.py 的 `I_A` 列）；抖得厉害就把带宽调宽。
6. 效果在台子上不好看：空载 RS05 的摩擦小，被带走的峰值只有零点几度，手转电机机身也没法重复，gimbal_watch.py 每 0.2 s 一行也看不出几十毫秒的过程。台子上主要验符号（第 4 步）；效果等上车、小陀螺时看。装上云台负载、滑环以后要重测（csv 删掉），见下一节。

### 上车重测（2026-11-10 用户问：转盘上什么都不接，上车以后摩擦不会变吗。还没做）

- 会变，多半变大。
  - 变大：云台的重量、重心偏出 yaw 轴的力矩压在 yaw 轴承上（RS05 自己的，或另加的），轴承摩擦随负载变大；滑环电刷、另加的轴承、线都是额外的一份；运行中底盘加减速、颠簸、pitch 角度也在改负载。
  - 变小：润滑脂热了变稀，还有磨合。
  - 所以台子上测的只是电机自己那份。
- 台子上测的用处有三个：
  - 把测、fit、填宏、验符号跑通。
  - 有个电机自己的底数：车上测完一减，就知道负载和滑环加了多少，大得离谱先查轴承是不是压太紧、不同心。
  - 车上重测之前先用它：车上摩擦一般只大不小，等于补少了，是安全方向。
- 符号台子上验对了，车上也对。
  - 方向系数在 `Gimbal_AxisRead`（转速）和 `Gimbal_AxisOutput`（电流）里各乘一次，前馈又是转速的奇函数，所以落到电机上的前馈电流总和电机自己的转向同号。
  - RS05 正电流、正转速同号（11-09 实测）。
  - 跟方向系数、电机正装反装都无关。脚本每次测也会再查一遍。
- 上车照样用 `yaw_friction.py`：脚本不管带不带负载，只要求没有线跨过转轴、没有东西挡着。要注意：
  1. yaw 能连续转：滑环装好，底盘和云台之间的线都走滑环。
  2. 先按车上的惯量把 yaw 的 PID 调好：脚本靠速度环稳住匀速，转速抖的话，匀速段的样本会被筛掉。
  3. 先转几分钟，连着测几次，后面不再比前面小了，删掉 csv 再正式测。
  4. 调试线：C 板在云台上，会跟着转。
     - 正反交替，测完回到起点附近，所以线最多被拧一趟的路程：约 0.5 s × 转速 + `--cover` + 15°。100°/s 时，默认 `--cover 360` 约 425°，`--cover 180` 约 245°。
     - 线从 yaw 轴正上方垂下来、留够长度，别挂到枪管、pitch 上；或者测的时候把 C 板临时挪到底盘上（模式 1 用不到 IMU）。
     - 脚本里“模式 2 要先把 C 板拿下来”的提示是按台子写的，到时候再改。
     - 转的时候人离远点。
  5. 惯量大了，起步、刹车都慢。
     - 起步落后、刹车冲过头都约 v²/(2α)，α 是电流限幅能给的角加速度。
     - 台子上 300°/s 时约 8°（`FOLLOW_LIMIT_DEG` 旁边的注释），和总惯量成正比。车上总惯量到台子上（约 0.0067 kg·m²）的 5 倍左右，最快那趟就会超过 45°，报“跟不上”停下。
     - 到时候临时放宽 `GIMBAL_CURRENT_LIMIT`，或者先不测那么快。
- 小陀螺能转以后，那才是真实工况：IMU 模式下云台对地不动，线不会拧，匀速转时 yaw 的电流就是那个相对转速下的摩擦。到那一步可以给脚本加一个只读的录制模式，在小陀螺里直接测，现在不写。
- 测一次就够用：
  - 前馈只补一个保守的下限：80%，且不超过任何位置的最小值。
  - 测不准的、慢慢变的部分（温度、磨合、负载）交给速度环积分。前馈只管相对转速一变、积分还没跟上的那一下。
  - 机械动过（换轴承、滑环、重装）再重测。
